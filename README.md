# PocketSmart AI

PocketSmart AI is a Generative AI based budgeting and recommendation application.

## Features

- Home Interior Budget Planner
- Party Budget Planner
- Jewelry Budget Planner
- AI-powered recommendations
- Budget-based suggestions
- Simple web interface

## Technologies Used

- Python
- FastAPI
- HTML
- CSS
- JavaScript
- Google Gemini API
